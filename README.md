# Savanna Table 🍽️

Savanna Table is a modern, responsive restaurant website designed to provide customers with an attractive and user-friendly way to explore the restaurant, view its menu, learn about its services, meet the chefs, and make a table reservation.

The project was created as a web development project to demonstrate practical skills in HTML, CSS, and JavaScript.

## 🍴 About the Project

Savanna Table is a fictional modern restaurant website inspired by the warmth, richness, and beauty of African dining.

The website is designed to create a welcoming online experience where visitors can discover the restaurant and its offerings before visiting.

The project focuses on clean structure, attractive visual design, responsive layouts, accessibility, and interactive user experiences.

---

## 🎯 Project Goals

The main goals of this project are to:

- Create a professional restaurant website.
- Practice semantic HTML.
- Apply modern CSS styling and responsive design techniques.
- Build layouts using Flexbox and CSS Grid.
- Create an intuitive navigation system.
- Implement a responsive hamburger menu.
- Add JavaScript functionality and interactivity.
- Practice writing clean and maintainable code.
- Create a website that works across different screen sizes and devices.

---

## 👥 Target Audience

The website is designed for:

- Families looking for a restaurant.
- Individuals looking for a dining experience.
- Tourists interested in African-inspired cuisine.
- Couples looking for a place to dine.
- Groups and event organizers.
- Customers interested in restaurant services.
- People looking for a convenient place to make a reservation.

## ✨ Features

### Navigation

The website includes a navigation bar with links to the main sections:

- Home
- About
- Menu
- Services
- Chefs
- Contact
- Book a Table

The navigation is responsive and includes a hamburger menu for smaller screens.

### Hero Section

The hero section introduces visitors to Savanna Table with an attractive visual presentation and a clear call-to-action.

### About Section

The About section introduces the restaurant and communicates its identity, values, and dining experience.

### Menu Section

The menu section presents selected dishes offered by the restaurant.

### Services Section

The services section highlights the different services offered by the restaurant.

### Chefs Section

The chefs section introduces the people responsible for preparing the restaurant's dishes.

### Contact Section

The contact section provides customers with information they can use to get in touch with the restaurant.

### Booking Section

The website includes a call-to-action that allows visitors to proceed toward making a table reservation.

Semantic elements such as:

- Typography
- Colors
- Spacing
- Responsive design
- Flexbox
- CSS Grid
- Hover effects
- Transitions
- Buttons
- Cards
- Shadows
- Border radius

### JavaScript

JavaScript is being introduced to add interactive behavior to the website.

One of the first planned JavaScript features is the responsive hamburger navigation menu.

## 📱 Responsive Design

Savanna Table is designed to work across different screen sizes, including:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

CSS media queries are used to adapt the layout to smaller screens.

For example, on mobile devices:

- Navigation links are hidden.
- The hamburger button becomes visible.
- The booking button can be hidden to keep the navigation compact.
- Content adjusts to fit smaller screens.
